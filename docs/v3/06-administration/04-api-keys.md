# API keys

> [!NOTE]
> **Required role:** `account_admin`

Create, rotate and revoke API keys used by CI/CD scanners and REST API integrations. Each key has a name and scope.

The menu entry **API keys** opens the hub **Scanners & API keys**, which also leads to **Release keys**, **CSAF feed keys** and the API usage statistics.
