# Login History

> [!NOTE]
> **Required role:** `account_admin`, `manager` or `compliance_manager`
> **How to open it:** select **Logins history** on the [Audit Logs](07-audit-logs.md) page. It is not a separate menu entry.

The login history lists the sign-in attempts of your company. Use it for security audits or when a colleague cannot sign in.

📸 *Screenshot: the Logins history page.*

## Read the list

The newest entries come first.

| Column | Description |
|---|---|
| **Allowed** | `yes` if the sign-in succeeded, `no` if it was refused. |
| **Created** | When the attempt happened. |
| **Method** | The sign-in method name. |
| **Type** | The type of the attempt. |
| **Email** | The email address of the user. |
| **Name** | The name of the user. |

## Related buttons

- **Audit logs** goes back to the [Audit Logs](07-audit-logs.md).
- **Users with no logins for 60 days** lists members who have not signed in during the last 60 days, with **Created**, **Email** and **Name**. Use it to find accounts you may remove.
- **Export as CSV** and **Copy to clipboard** take the list with you.
