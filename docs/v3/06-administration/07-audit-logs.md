# Audit Logs

> [!NOTE]
> **Required role:** `account_admin`

The audit log records significant actions in your company: who did what and when. Examples are role changes, integration changes, invitations and approvals. Open it from **Administration → Audit logs**.

📸 *Screenshot: the Audit logs page.*

## Read the log

The newest entries come first. Each row shows:

| Column | Description |
|---|---|
| **Date** | When the action happened. |
| **Company** | The company the action belongs to. |
| **Name** | The user who performed the action. |
| **Type** | The event type with its short name in brackets. |
| **Action** | A description of what happened. |

## Search and filter

Use the search bar to look for text in the **User name**, **Event** and **Message** fields. Open the advanced filter to narrow the list to one **Event type**.

## Export

- **Export as CSV** downloads the log.
- **Copy to clipboard** copies the log so you can paste it into another tool.
- **Logins history** opens [Login History](09-login-history.md), the list of sign-in attempts.
