# Recipe: Onboard a Team Member

Invite a new user and get them productive.

## Steps

1. Go to [Administration → User Management](../06-administration/03-user-management.md).
2. Under **Invite your colleagues**, enter the **Name** and **E-Mail** and click **Invite**.
3. The user starts with the role `developer`. Assign the appropriate [roles](../10-roles-permissions/01-roles-overview.md) in the user list.
4. The user receives an enrollment email and sets up their account.
5. Share links to [Getting Started](../00-getting-started/index.md) and the [5-Minute Tour](../00-getting-started/04-quick-tour.md).
