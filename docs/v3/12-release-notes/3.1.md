# v3.1: Release Notes

> **Covers:** 3.1.21 (2026-06-10)
> **Source:** the [Updates](../08-personal/01-updates.md) feed in ***TrustSource***.

This page follows the entries of the **Updates** feed for the v3.1 series. Items are grouped as in the feed under **New**, **Improvement** and **Fix**.

## 3.1.21 (2026-06-10)

### New

- **CycloneDX 1.7:** support for CycloneDX 1.7 SBOMs and the features that come with it. It describes more algorithm data and provides the AIBOM, which is also available through the API and in the module settings. See [AI / ML](../03-internal/02-modules/settings/19-ai-ml.md) and the [CycloneDX 1.7 announcement](https://cyclonedx.org/news/cyclonedx-v1.7-released/).
- **API:** new methods in the risk area to manage countermeasures through the API: read suggested countermeasures, define your own and get their resolution status. See [Risks](../09-rest-api/endpoints/risks.md).
- **MCP server:** an MCP server for the ***TrustSource*** API, available as open source and as a Docker image on Docker Hub. It needs a ***TrustSource*** API key with sufficient rights. Added as a tool to, for example, a Claude session, it lets you direct ***TrustSource*** activities in natural language. See [ts-mcp](https://github.com/TrustSource/ts-mcp).
- **Online help:** a new online help with new texts. Its structure is maintained automatically and feeds the chatbot, so OSCAR stays up to date with the latest features.

### Improvement

- **Security:** old MD5 hash algorithms were replaced by HMAC-SHA256.
- **Risk management:** new attributes support STRIDE, ENISA, CWE and OTM, and the document store can hold threat models, in preparation for threat models on project level.

### Fix

- **Security:** authentication and authorization issues in the DDP connection were fixed, with a review and redesign of the internal communication.
- **Crypto:** the type of a crypto asset can be edited again.
- **API:** some API methods that the security hardening above had blocked work again.
- **Legal:** duplicate license obligations caused by a technical upgrade were removed.
