# v3.0: Release Notes

> **Covers:** 3.0.6 to 3.0.19 (2026-05-20 to 2026-06-02)
> **Source:** the [Updates](../08-personal/01-updates.md) feed in ***TrustSource***.

This page follows the entries of the **Updates** feed for the v3.0 series, newest first. Items are grouped as in the feed under **New**, **Improvement** and **Fix**.

## 3.0.19 (2026-06-02)

### New

- **Products:** a complete REST API for products, to automate product handling and prepare further automation of vulnerability analysis, triage and reporting. It includes a `parentId` reference, so the product hierarchy can be rebuilt. See [Products](../09-rest-api/endpoints/products.md).
- **CSAF:** an access-controlled REST feed of a company's CSAF documents, so access can be controlled by TLP level. Manage access keys for your customers as **CSAF feed keys**, the same way as SBOM and release keys. See [CSAF trusted provider](../13-capabilities/06-csaf-trusted-provider.md).

### Improvement

- **Dark theme:** the Category and crypto-algorithm tag inputs and the license fields (declared, effective, concluded) have proper dark styling and a teal focus ring like the other inputs. The list filter was improved.

### Fix

- **Security:** WebSocket vulnerabilities that allowed information disclosure through unauthenticated injection were reported by an external security researcher and fixed.
- **Login:** an earlier security patch limited URL forwarding and made corporate logins less fluent; this is fixed.
- **Check:** bad or empty input no longer fails silently; the function says clearly that it cannot process the input.
- **Learning:** **Buy course** on a paid course in the training panel opens the Stripe checkout, which returns to the course page after payment. See [Trainings](../05-knowledge/08-trainings.md).
- **Settings:** the **Settings** section under **Administration** is visible to the compliance, security, portfolio and manager roles as well as account administrators. Each settings page appears only for the roles that own it, and users without a matching role do not see the menu item. See [Settings](../06-administration/02-settings.md).

## 3.0.6 (2026-05-20)

### New

- **Threat models:** support for threat modelling. From the scan data and your input in the settings, generate a stub as an Open Threat Model or OWASP Threat Dragon definition, to export and assess further in tools such as IriusRisk or Threat Dragon. See [Threat models](../03-internal/08-threat-models/index.md).
- **Vulnerability supply:** more sources and better matching, which unifies entries from different sources on the same issue, and the information per source is shown. This also prepares private vulnerabilities. EACG, the company behind ***TrustSource***, is registered as one of Europe's first gCNAs (ID 102), so subscribers can register and report their own CVEs through the TrustSource Trusted Provider. See [CSAF trusted provider](../13-capabilities/06-csaf-trusted-provider.md).
- **Bulk scans:** hand an SBOM to ***TrustSource*** to download all artifacts of the transitive dependency list and scan them file by file. This helps to understand the use of encryption algorithms and to identify copyrights for sound notice files. Each scanned component counts against your transaction budget; a private scanning option in your own cloud is available on request. See [Mass scans](../02-inbound/06-mass-scans.md).
- **Training platform:** a new training platform with courses on features and skills around software supply chain security and product security. Course finishers receive badges. Depending on your subscription, courses are included or paid separately. See [Trainings](../05-knowledge/08-trainings.md).
- **Risk management:** API methods to manage risks from outside and read risk information. See [Risks](../09-rest-api/endpoints/risks.md).

### Improvement

- **OSCAR:** the chatbot moved to the right side of the screen and is available on every page. Code snippets are easier to copy, and its knowledge base keeps growing. See [OSCAR chat](../13-capabilities/01-oscar-chat.md).
- **Menu structure and layout:** refreshed design and a restructured main menu.

### Fix

- **Security:** security patches prevent misuse of WebSocket information.
