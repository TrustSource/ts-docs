# v3.1.20 — Release Notes

> **Date:** 2026‑06‑09
> **Audience:** All users.

This is the baseline version this documentation track was originally
written against.

## Added

- New **AI / ML Bill of Materials (AIBOM)** capability. Machine-learning
  model components arriving via a scan or a CycloneDX import are captured as
  AI artifacts on the module. A new "AI / ML BOM" tab in module settings
  lets you review detected models and add, edit, remove and export the
  managed AI artifacts as a CycloneDX AIBOM.
- New REST endpoints to request a module's or project's AIBOM and CBOM as a
  CycloneDX document.
- CycloneDX export now offers a combined **"Full BOM"** option (components +
  cryptographic assets + AI artifacts) from the Crypto management and AI/ML
  BOM tabs, and from the Bill of Materials report's export menu.

## Fixed

- Requesting a module's or project's SBOM through the REST API no longer
  fails with "403 Access Denied", and cryptographic-asset (CBOM) data is now
  returned correctly.
- Generating a notice or release at the project level no longer fails when a
  license still has obligations to configure.
