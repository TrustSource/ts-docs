# COTS

The COTS (Commercial Off-The-Shelf) catalogue holds the commercial software components of your company — products you license rather than build. Unlike open-source components found by scans, they are maintained by hand. Open it from **Knowledge → COTS**.

## Browse the catalogue

Filter the list and select a component to open its page. It shows the **Information** (key, purl, homepage, repository, language, last update), the **Comment**, the **Versions** and the component's **commercial terms**: *Right to re-sell*, *Right to distribute* and *Right to host/operate as SaaS*, each rated *unlimited*, *limited* or *no*. In this view the terms are read-only.

> [!NOTE]
> Everyone can read the catalogue. Users with the `component_manager` role also see **Add COTS component**, **View used as Modules** and an **Edit** button. See [Manage COTS Components](../14-component-manager/02-manage-cots.md).

COTS components are linked to modules of the COTS type; see [Infrastructure modules](../03-internal/02-modules/03-infrastructure-modules.md) for the comparable workflow.
