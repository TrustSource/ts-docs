# COTS

The COTS (Commercial Off-The-Shelf) catalogue holds commercial software components: products you license rather than build. Unlike open-source components found by scans, they are maintained by hand by users with the internal `component_manager` role. Open it from **Knowledge → COTS**; the page is titled **COTS components**.

## Browse the catalogue

Filter the list and select a component to open its page. It shows the **Information** (key, purl, private flag, homepage, repository, issues, release notes, language, last update), the **Comment**, the **Versions** and, if they were entered, the component's **commercial terms**: *Right to re-sell*, *Right to distribute*, *Right to host/operate as SaaS* and *Right to modify*, each rated *unlimited*, *limited* or *no*. In this view the terms are read-only.

> [!NOTE]
> Everyone can read the catalogue. Users with the `component_manager` role also see **Add COTS component**, **View used as Modules** and an **Edit** button. See [Manage COTS Components](../14-component-manager/02-manage-cots.md).

COTS components are linked to modules of the COTS type; see [Infrastructure modules](../03-internal/02-modules/03-infrastructure-modules.md) for the comparable workflow.
