# Knowledge

The Knowledge section provides global reference databases shared across all projects. These are the data sources that ***TrustSource*** uses to enrich your scans with license obligations, vulnerability data, algorithm classifications and policy rules.

| Page | What it covers |
|---|---|
| [Component Lake](01-component-lake.md) | Component library: search the public index, your own components or the full database. |
| [Infrastructure Elements](02-infrastructure-elements.md) | Catalogue of infrastructure components: operating systems, base images, databases, web servers. |
| [COTS](03-cots.md) | Commercial off-the-shelf component catalog. |
| [Vulnerability Lake](04-vulnerability-lake.md) | Search products, CVEs and CWEs; CVSS scores, CISA exploit alerts, subscriptions. |
| [Algorithms](05-algorithms.md) | Cryptographic algorithms with post-quantum (PQC) status, substitutes and standards. |
| [Licenses](06-licenses.md) | License database with full license texts. |
| [Open Source Policy](07-open-source-policy.md) | Read your company's active open source policy. |
| [Trainings](08-trainings.md) | Training courses inside the app, or your company's own training portal. |
