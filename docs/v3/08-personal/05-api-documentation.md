# API Documentation Browser

Browse the built-in interactive API documentation and try calls from the browser. It is generated from the OpenAPI specification of the [REST API](../09-rest-api/index.md).

## Open it

Select the **API documentation** icon in the right-hand icon bar. The page shows the operations grouped by tag, with their parameters and responses.

## Try a call

1. Select an operation and choose **Try it out**.
2. Enter your [API key](../06-administration/04-api-keys.md) as `x-api-key`.
3. Fill in the parameters and execute the call.

> [!WARNING]
> Calls you run here act on your real data. A `POST` or `DELETE` changes your account.
