# Updates Feed

The **Updates** page ("TrustSource list of available updates.") shows the release notes and announcements of ***TrustSource***. Open it with the bell icon **Updates** in the right bar. When there are entries you have not opened yet, the icon is titled "Unread updates available" and shows a dot.

📸 *Screenshot: the Updates page with the latest version entry and its New, Improvement and Fix items.*

Each entry shows the version, its publication date and its items, grouped under **New**, **Improvement** and **Fix**. An item can link to more information with **View details**. Entries appear once their publication date is reached; the newest come first.

For a summary per release series, see the [Release Notes](../12-release-notes/index.md).
