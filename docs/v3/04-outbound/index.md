# Outbound

This chapter covers the documents you generate from ***TrustSource*** for external consumption: SBOMs, CBOMs, attribution files, SOUP lists, CSAF advisories, CVD cases and the verification tool.

| Page | What it covers |
|---|---|
| [SBOM + CBOM](01-sbom-cbom.md) | Create, edit, freeze and download Software, Cryptography and AI / ML Bills of Materials (CycloneDX JSON, SPDX JSON). |
| [Notice Files](02-notice-files.md) | Attribution (open-source notice) file generation and maintenance. |
| [SOUP Lists](03-soup-lists.md) | Software of Unknown Provenance lists for medical devices. |
| [CSAF](04-csaf.md) | CSAF security advisories: create, check, publish and share through feed keys. |
| [CVD Cases](06-cvd-cases.md) | Coordinated Vulnerability Disclosure cases held in the connected CVD platform. |
| [Verify](05-verify.md) | Check the signature of a release document issued by TrustSource. |

> [!TIP]
> An [approval](../03-internal/06-approvals/index.md) creates the SBOM file, the notice file and, where licensed, the SOUP file of its release automatically. You can also create them on demand for a project or a module on the pages of this chapter.
