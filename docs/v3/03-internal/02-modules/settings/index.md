# Module Settings

Module settings are organized in tabs (nineteen in the UI, depending on module type, license and role). Most settings inherit from the parent project and can be overridden at the module level.

| Tab | What it configures |
|---|---|
| [General](01-general.md) | Name, description, project assignment, architecture type, version, tags. |
| [Legal](02-legal.md) | License obligations, legal template assignment. |
| [Resolved obligations](03-obligations.md) | Obligation resolution status per component. |
| [Viability](04-viability.md) | Repository health monitoring, activity thresholds. |
| [OSSF](05-ossf.md) | OpenSSF Scorecard configuration and thresholds. |
| [Versioning](06-versioning.md) | Component version tracking, jump detection. |
| [MDR/IVDR Classification](07-module-classification-mdr-ivdr.md) | Medical device classification (Medical accounts). |
| [CIA](08-cia.md) | Confidentiality, Integrity, Availability requirements. |
| AI / ML | AIBOM settings; not shown for infrastructure modules (page still to be written). |
| [Capabilities](09-capabilities.md) | Software capability declarations. |
| [Crypto management](10-encryption.md) | Cryptographic algorithm and export control settings. |
| [End-of-life](11-end-of-life.md) | EOL analysis thresholds. |
| [Quality](12-quality.md) | Test and quality requirements. |
| [History](13-releases.md) | Module version history and release tagging. |
| [Allow/Deny](14-whitelists-blacklists.md) | Allowed/denied licenses and components. |
| [Allowed vulnerability](15-cve-whitelist.md) | Accepted vulnerabilities (known-risk exceptions). |
| [Custom components](16-custom-components.md) | Manually defined components not from scans. |
| [Export SPDX](17-spdx-export.md) | SPDX document generation settings. |
| [Danger Operations](18-danger-zone.md) | Delete or archive the module. |
