# CIA (Module)

> [!NOTE]
> **Required role:** varies by field — see [Settings Permission Matrix](../../../10-roles-permissions/06-settings-permission-matrix.md)

Confidentiality, Integrity and Availability requirements — can be higher than project level. The stricter value of module and project counts when ***TrustSource*** proposes an impact class for an automatically created risk; see [Risks List](../../05-risks/02-risks-list.md#proposed-impact-class).

## Risk assessment scheme

With the `risks` feature, the panel **Risk assessment scheme** below the requirements overrides the project's (or else the company's) [risk assessment scheme](../../05-risks/07-risk-assessment-scheme.md) for this module only. Anything you do not override is inherited. Changing it needs `account_admin`, `manager` or `compliance_manager`.
