# Help and Contact

***TrustSource CE*** is a self-hosted, open source edition. There is no vendor support desk built into the app; help comes from this documentation, your own administrators and the project on GitHub.

📸 *Screenshot: the right bar with the Help and Contact Account Admin icons highlighted.*

## In the app

| Right bar icon | What it does |
|---|---|
| **Guide for this screen** (compass) | Opens the guide panel with a tour for the current screen, where one exists. See [Guide and demo](../00-getting-started/08-guide-and-demo.md). |
| **Help** (question mark) | Opens the README of the TrustSource CE repository on GitHub, `https://github.com/TrustSource/ts-core-ce#readme`. On small screens the same link is called **Support** in the menu. |
| **Contact Account Admin** (paper plane) | Opens a new email in your mail program, addressed to your company's **Distribution email** if one is set under [General info](../06-administration/02a-company-details.md), otherwise to the first Account admin of your company. The icon is hidden when no address is found. |

## Questions about your installation

Ask your Account admin for access, roles and company settings, and the operator who runs the installation for problems with sign-in emails, updates, backups or the server itself. Operators find setup and operation help in [Installation & Setup](../01-installation-setup/index.md) and [Troubleshooting](../11-troubleshooting-faq/index.md).

## Report a problem

Report bugs and ask questions about TrustSource CE itself in the issue tracker of the GitHub repository `https://github.com/TrustSource/ts-core-ce` (tab **Issues**). Describe the version (shown in the sidebar footer, for example "TrustSource CE 1.0.0"), what you did and what happened, and leave out keys, passwords and customer data.

See [Contact & support](../11-troubleshooting-faq/06-contact-support.md).
