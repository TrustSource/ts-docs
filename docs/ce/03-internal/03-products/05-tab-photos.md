# Tab: Photos

> [!NOTE]
> **Editing:** Developer, Compliance manager, Company security manager or Account admin.

The **Photos** tab is a gallery of pictures and illustrations of the product, useful for identification and regulatory documentation.

## Upload a picture

1. Click **Upload additional pictures or illustrations**.
2. Select an image. Accepted formats: JPG, JPEG, PNG, WEBP, GIF, AVIF, SVG, HEIC and HEIF.

The upload starts immediately (the button shows *Updating product* meanwhile) and the picture appears in the gallery. Other file types are rejected with "Invalid file type. Please upload a valid image."

## Browse and remove

Use the gallery to page through the pictures. To delete one, show it and click **Remove picture**; the button is visible once at least one picture exists. The file is removed from the server as well.

Each picture stores who uploaded it and when. Photos can be downloaded together with the product documents; see [Documents](06-tab-documents.md#download-everything).

## Where pictures are stored

***TrustSource CE*** keeps product pictures on its own file storage (the `ts-files` volume in the reference setup) and serves them under `/files/products/...`. See [Documents](06-tab-documents.md#where-documents-are-stored) for what that means for access and backups.
