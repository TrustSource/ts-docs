# Internal

This is the largest chapter in the ***TrustSource CE*** documentation. It covers everything you do between bringing data in ([Inbound](../02-inbound/index.md)) and producing compliance documents ([Outbound](../04-outbound/index.md)). In the sidebar these pages sit under **Internal**.

## In this chapter

| Section | What it covers | Key roles |
|---|---|---|
| [Products](03-products/index.md) | Products with CRA classification, contacts, photos, documents, misuse cases and solution links. | Developer, Compliance manager, Manager, Account admin |
| [Projects](01-projects/index.md) | Create, configure and manage projects, the containers for your modules. 12 settings tabs. | Manager, Compliance manager |
| [Modules](02-modules/index.md) | The unit of analysis: components, licenses, vulnerabilities, dependencies. 5 views, 17 settings tabs. | Developer, Compliance manager, Manager |
| [Risks](05-risks/index.md) | Risk register with overview, risk list and tasks. | Developer, Compliance manager, Manager, Account admin |
| [Approvals](06-approvals/index.md) | Formal release approvals, the quality gate before shipping. | Compliance manager, Manager |
| [Releases](07-releases.md) | Approved module releases with frozen SBOMs and post-release vulnerability monitoring. | All roles |
| [Reports](04-reports.md) | Hub page with all analysis, impact and portfolio reports. | Developer, Compliance manager, Manager, Account admin |

> [!TIP]
> The typical workflow is: **create a project**, **add modules**, **scan**, **review findings**, **approve**, **release**, **generate documents**. Follow the sections in that order for a natural path through the app.

Threat model generation, MDR/IVDR classification and the OBOM tab are not part of TrustSource CE; see [CE and SaaS compared](../13-ce-vs-saas.md).
