# Getting Started

These pages are for **first-time users** of ***TrustSource CE***. Read them in order if you have never used the app before, or pick a single page if you know what you are after.

> [!NOTE]
> If nobody has installed TrustSource CE for you yet, start with [Installation & Setup](../01-installation-setup/index.md). The pages below assume a running installation and a user account.

| # | Page | What you get out of it |
|---|---|---|
| 1 | [What is TrustSource CE?](01-what-is-trustsource.md) | What the app does, what it does not do, and what "self-hosted, AGPL-3.0" means for you. |
| 2 | [Your First Login](03-first-login.md) | Signing in, two-factor authentication, invitations, password reset, self sign-up, and where things live in the app. |
| 3 | [A 5-Minute Tour](04-quick-tour.md) | Click-through of the six main menu groups and the right bar. |
| 4 | [Mental Model](05-mental-model.md) | The core data structure - Projects, Modules, Components, Products - and how they relate. |
| 5 | [Roles Cheat Sheet](06-roles-cheatsheet.md) | One page for the seven roles and who can do what. |
| 6 | [The Dashboard](07-dashboard.md) | The welcome banner and the widgets each role sees. |
| 7 | [Guide, tour and demo project](08-guide-and-demo.md) | The in-app guide panel, the guided tours and the demo project to try the app with sample data. |

> [!TIP]
> If you only have five minutes, read [What is TrustSource CE?](01-what-is-trustsource.md) and the [Mental Model](05-mental-model.md), then load the [demo project](08-guide-and-demo.md#demo-project). Together they give you the vocabulary and a module to click through.
