# Your Open Source Policy

**Knowledge → Open source policy** shows your company's active open source policy in ***TrustSource CE*** ("Last active policy updates for company"). Compliance managers publish the policy as a document under [Administration → Policies](../06-administration/05-policies.md); here every user reads the active version.

The page shows the policy name, **Active from**, the description, a **View policy file** link to the document and the date it was last **Updated**. Opening the file is recorded, so the compliance manager can see who has viewed the policy.

If no policy is active, the page says *Your company does not yet have an active open source policy* and offers email links to the company's **Compliance manager** and **Account administrators**.

## New policy updates

When a new policy becomes active, users see a **New policy updates** dialog after signing in, with the same details. Open the file and click **Confirm** to acknowledge it; until you have viewed the file, the dialog reminds you: *You should review new policy first*. Viewing and confirming are written to the company's audit log, and the compliance manager sees the counts in the policy list.
