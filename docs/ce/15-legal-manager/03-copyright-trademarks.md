# Copyright & Trademarks

> [!NOTE]
> Every signed-in user can open the page. Nobody can edit it.

The **Copyright & Trademarks** page lists the third-party tools, data sources and trademarks used in ***TrustSource CE*** ("Tools and trademarks used in TrustSource CE"). Open it from the copyright line (EACG) at the bottom of the left menu; the address is `/copyright_trademarks`.

The page starts with a short statement: the app combines many new and existing tools, EACG is neither owner of nor related to these brands and trademarks, and the use of a logo or trademark does not mean that its owner endorses TrustSource. Each entry then shows:

- its name, with an anchor link you can copy to point directly at the entry,
- a description of the tool or data source and its license,
- how TrustSource CE uses it,
- a **View** link to the source, where one exists.

## Where the entries come from

The list ships with TrustSource CE and is read-only. Every start of the app restores the shipped entries, so changes made directly in the database do not last. There is no screen to add or edit entries.
